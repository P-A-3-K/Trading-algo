Portfolio several strategies, one account

Each row (a leg) is a ticker, timeframe and strategy with a weight (share of the account). They are backtested separately and combined day by day. Legs that don't move together cancel part of each other's bad days, so the whole can be smoother than any part. Weights can add up to more than 100% (leverage) or less (cash).

Each leg and the whole each leg's own numbers at 100%; the portfolio uses the weights

How the legs move together correlation of daily returns: 1 = in lockstep, 0 = unrelated, −1 = opposite

Combined daily, rebalanced to the weights each day. Losses for the prop check add up each leg's lowest point of the day (cautious).
