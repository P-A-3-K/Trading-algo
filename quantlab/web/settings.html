Alpaca: years of intraday candles, free

  1. Make a free account at alpaca.markets (no deposit needed).
  2. In the dashboard, open Paper Trading and find API Keys (on the home page, right side). Click Generate New Keys.
  3. Copy the API Key ID and the Secret Key into the boxes below. Alpaca shows the secret only once, so keep the page open until you've saved.

The keys are saved in alpaca_keys.json in your QuantLab folder. Git ignores that file, so it's never uploaded; QuantLab only sends the keys to Alpaca. Market data works with paper-trading keys: nothing here can place trades.

MetaTrader 5: your prop firm's own prices

Test strategies on the exact instruments you'll trade (e.g. FTMO's US100.cash, XAUUSD), with their real spread on every candle and their overnight swap fees. Works with any MT5 broker or prop firm, demo or real.

  1. Install MetaTrader 5 on this Windows PC and log in (e.g. an FTMO free trial or challenge account).
  2. In the QuantLab folder run once: .venv\Scripts\pip install MetaTrader5
  3. With MT5 open, download symbols (5-minute and daily history):
    .venv\Scripts\python -m quantlab.mt5 download US100.cash US500.cash US2000.cash XAUUSD
    Names differ per broker: .venv\Scripts\python -m quantlab.mt5 list cash shows them.
  4. Use them anywhere in QuantLab with the MT5: prefix, e.g. MT5:US100.cash (chart, Optimize, Portfolio).

QuantLab converts the server's clock to New York time, uses each candle's spread instead of an estimate, and charges the symbol's swap for every night a position is held (3 over a weekend). Nothing here places trades.

Import candles from CSV files

For history no free API offers, e.g. years of European index candles from Dukascopy's historical data export (free account; choose the instrument, 1 minute, and a date range; download CSV), or an export from MT5.

.venv\Scripts\python -m quantlab.importer GER40 "C:\Users\you\Downloads\GER40*.csv"
then use CSV:GER40 as a ticker. Times are read as UTC unless the file says otherwise (or add --tz UTC+2).
